# Visual asset provenance

`logo.png` and `banner.png` were generated for this repository with OpenAI's
image generation tool on 2026-09-04, directed and selected by the repository
author. They are repository-owned assets distributed under MPL-2.0 with the
source tree.

The prompts required an original camera-frustum, scene-grid, atmosphere, and
lighting visual language and explicitly excluded text, trademarks, and Epic or
Unreal logo shapes. No Unreal Engine, Fab, Marketplace, or third-party art
assets are included.
